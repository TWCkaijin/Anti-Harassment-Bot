# 2026-10-09 修正與驗證

- 一般聊天、管理員測試與行為測試改為自動本機遮罩後送出；移除逐次確認視窗及其設定。舊 privacy_review_required 欄位只供 API 相容，舊值不會讓視窗重新出現。送出使用註冊且不可變的請求快照，保留取消、會話切換、摘要版本與重試檢查。
- guided_v4 兩階段與單階段模型請求使用 strict JSON Schema，供應商路由要求 require_parameters；不支援 schema 的錯誤不降級成純 prompt。補上非串流完成狀態、單一 choice、嚴格型別與非法 JSON 常數檢查。其他使用 JSON Schema 的代理也共用供應商能力要求。
- 測試只使用合成 fixtures，隔離副本排除 resource、data 與正式憑證。pytest 禁止 dotenv 載入；瀏覽器 fixture server 不初始化 Firebase，也不呼叫外部模型。修正過時的 v4 瀏覽器斷言、品質工具的隱含輸入路徑及文件首次建置自我連結問題。

## 適用邊界

本次沒有部署或呼叫真實模型。Schema 能力要求與本機驗證已測試，實際供應商的原生解碼能力仍須在獲授權的連線測試驗證。PII 使用現有本機規則遮罩；先前未通過門檻的小模型尚未整合，不能把本次修改視為完整 PII 辨識保證。
