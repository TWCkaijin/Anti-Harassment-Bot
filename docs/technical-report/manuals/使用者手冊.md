# 性騷擾防治智能 AI 使用者手冊

版本日期：2026-10-10。適用於獨立 Client 網站的 v4 功能；管理功能已移至獨立 Admin 網站，實際畫面依服務版本及管理設定而定。

## 1. 開始前

先描述你希望得到的協助，例如「我在工作時收到讓我不舒服的訊息，想了解可以怎麼處理」。通常不需提供姓名、公司／學校全名、地址或證件資料，可用「我」「主管」「同學」「對方」等角色說明。

回答是初步資訊，不能取代專業判斷。電話及網站按鈕只開啟相應工具，不會自動替你申訴或報案。

## 2. 提問與自動送出

1. 在輸入區描述問題，可依畫面功能選取或貼上圖片。
2. 按傳送後，瀏覽器會遮罩本次訊息、歷史與摘要，再自動送出；首次輸入也不會出現確認視窗。
3. 若本機處理失敗，依畫面提示修改後重試；停止或切換對話可取消尚未完成的處理。
4. 閱讀逐段出現的回覆，等待完成後再使用追問選項或資源按鈕。

自動遮罩可能漏掉姓名、地址或特殊細節，不能保證完全匿名。圖片支援 PNG、JPEG、GIF、WebP，每張最多 5 MiB；原圖不會自動去識別，傳送前應自行處理不希望外送的內容。圖片入口也可能由管理者停用。

## 3. 閱讀回答與處理過程

| 畫面 | 意義 |
| --- | --- |
| 處理過程 | 顯示實際收到的準備、檢索與生成階段，可收合；不是完成百分比 |
| 回答逐段增加 | 尚未完成；來源及按鈕可能等到完整回應確認後才出現 |
| 分析或推理說明 | 與正式答案分開閱讀，不當作已查證結論 |
| 已停止／處理中斷 | 已顯示內容可能不完整，稍後可重新提問 |
| 來源與限制 | 核對來源是否支持回答及適用你的情況；有來源不代表一定正確 |

模型未提供推理說明時仍可正常回答。不要因為回答流暢或有法名，就把具體期限及適用結果當成已核實事實。

## 4. 追問與情境摘要

系統可能詢問影響回答的必要資訊。依實際情況選擇答案，可自行補充、不確定或暫不提供；無須透露不想說的事情。

在最新有效 AI 回覆下方開啟摘要入口，檢查「目前摘要」。目前摘要是一段可編輯文字，不需照固定身分欄位填寫。

1. 查看摘要，確認人物關係、事件與需求是否正確。
2. 開始編輯會停止目前生成；只查看不會停止。
3. 按「儲存摘要」供後续提問使用，或「儲存並重新回答」依更正後情況回答原需求。
4. 如果不想變更，取消編輯。

例如把「同事」更正為「影響考績的直屬主管」，並保留你原本的疑慮。重新命名對話不會更正摘要。舊資料轉換時若摘要太長或版本不支援，依畫面提示處理，不要刪除原紀錄後才嘗試恢復。

## 5. 紀錄、匯出與刪除

對話保存在目前瀏覽器的 localStorage，關閉視窗後仍可能存在。側欄可切換、重新命名、刪除對話；設定可匯出或清除全部紀錄。

| 操作 | 影響與限制 |
| --- | --- |
| 新對話 | 開始新會話，先前紀錄不會自動刪除 |
| 匯出 JSON／文字 | 下載本機副本，包含訊息及摘要；reasoning 暫存內容不匯出 |
| 刪除紀錄 | 清除選定的本機資料，不會同步刪除既有下載檔 |
| 清除全部 | 清除本站本機對話，不代表第三方服務已刪除收到的內容 |

既有歷史、本機摘要、圖片與匯出仍可能含個資；送出前遮罩不會批次清除所有舊紀錄。共用裝置使用完畢後，請檢查紀錄與下載檔。私密模式也不是完整匿名保證。

## 6. 設定與常見問題

使用分析為選擇性功能，啟用條件包含網站設定及使用者同意；可在設定關閉。情緒標籤是閱讀提示，不能當作診斷。

| 問題 | 處理方式 |
| --- | --- |
| 回答誤解我的身分或關係 | 更正目前摘要後重新回答，勿只修改對話標題 |
| 圖片不能送出 | 檢查格式、大小及上傳開關；也可改用去除個資的文字 |
| 回答停在一半 | 查看中斷提示，稍後再試，勿把半段內容當作完整結論 |
| 沒有摘要或顯示版本不相容 | 請維運人員確認前後端版本，保留原對話資料 |
| 來源看起來過時 | 提供來源名稱請維運者核對，不自行當作確定法律依據 |
| 顯示請求過多或維護中 | 稍後再試，避免連續重送 |
