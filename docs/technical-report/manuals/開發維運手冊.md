# 性騷擾防治智能 AI 開發維運手冊

版本日期：2026-10-10。本文件提供拆分後架構與日常檢查摘要。完整環境變數、密碼管理、部署與回復命令集中於 [操作手冊](../../OPERATIONS.md)；實際驗收狀態見 [遷移報告](../../MIGRATION_REPORT.md)。

## 1. 安裝與本機程序

使用 Python 3.13、Node.js 24、pnpm 10.27.0、uv。由根目錄執行：

```bash
uv sync --frozen --all-extras
pnpm install --frozen-lockfile
```

不要覆寫既有環境檔。以 `.env.example` 建立獨立本機設定，讓 `RAG_ENV_FILE` 指向該檔，並設定 `PYTHONPATH=shared/python:client/backend:admin/backend`、`ENVIRONMENT=development` 與 `FLASK_SKIP_DOTENV=1`。後者停用 Flask CLI 自動載入根目錄 `.env`，讓 API 與 Python worker 都由共用設定模組讀取 `RAG_ENV_FILE`；已匯出的同名變數仍優先。業務庫使用 `app-dev`，設定文件為 `app_dev`，私有庫為 `admin-private-dev`。

| 程序 | 根目錄執行命令 |
| --- | --- |
| Client API | `uv run flask --app client_app.main:create_app run --port 8000` |
| Admin API | `uv run flask --app admin_app.main:create_app run --port 8001` |
| Client 網頁 | `pnpm --filter @rag/client dev`，port 5173 |
| Admin 網頁 | `pnpm --filter @rag/admin dev`，port 5174 |
| 本機 worker | `uv run python -m admin_app.worker_cli --poll-seconds 2` |

本機 Admin 使用 HTTP 時設定 `ADMIN_COOKIE_SECURE=false`。本機 worker 的 Cloud Tasks 設定需全部留空，並與 Admin API 共用同一套 project、database、Storage 設定；它只執行 development jobs。Storage 使用 ADC，本機執行仍可能呼叫真實 dev 資源與模型。

## 2. 模組與契約

| 目錄 | 職責 |
| --- | --- |
| `client/backend` | Client Flask app、聊天／health 路由、SSE wrapper |
| `client/frontend` | 聊天、摘要、歷史、匯出及使用者設定 |
| `admin/backend` | 密碼／session、設定、Skills、診斷 jobs、corpus、worker 與資料 CLI |
| `admin/frontend` | 獨立登入、管理設定、測試與檢索來源管理 |
| `shared/python/rag_core` | Agent、RAG、Runtime Config、契約、PII、內建 Skills |
| `shared/frontend` | 聊天契約、遮罩及前端共用服務 |
| `client/tests`、`admin/tests`、`shared/tests` | 各自回歸及共用測試 |
| `infrastructure` | 四庫 Rules、向量／私有索引、IAM、Emulator 測試 |

Client 支援聊天契約 1-4；v4 使用 schema 3 文字摘要，瀏覽器 storage schema 4。完整單元驗證後送出 delta，done 才提交摘要與 metadata。SSE wrapper 保持 lazy iterator 與關閉清理，不先讀完回應。詳細欄位見 [聊天契約](../CHAT_CONTRACT.md) 與 [API 參考](../API_REFERENCE.md)。

更動需覆蓋摘要 revision／過期結果、取消／重試、遮罩後請求快照、圖片邊界、未知 source ID、契約指紋、歷史遷移、Excel 原內容及人工覆核失效。

## 3. 資料與權限

同環境 Client／Admin 共用業務庫，collection 分工由後端 allowlist 控制。Client SA 只讀對應業務庫；Admin SA 可操作對應業務及私有庫。四庫 Rules 拒絕瀏覽器直連。不能以 Rules 測試取代 SDK 實際 IAM 驗收，也不宣稱 IAM 能限制 Admin SDK 只讀某些 collections。

Runtime Config 與 Skills 的寫入採 revision 比對，一般快取約 30 秒／Skills 約 60 秒。production／preview 缺少或錯配必要 database／document／secret 設定時拒絕啟動。管理密碼、sessions、CSRF、jobs 不能進入 Client 回應或公開產物。

原始 `data/`、`resource/`、`.env`、`.env.local` 及 `firebase_admin.json` 保留；[資料工具](../../../admin/backend/admin_app/scripts/README.md) 的搬移、catalog、apply 使用明確資料庫與核對過的計畫。不要把舊 seed 或預覽直接當成最新雲端計畫。

## 4. 測試與套件建置

```bash
uv run --frozen ruff check client/backend admin/backend shared/python client/tests admin/tests shared/tests scripts conftest.py
uv run --frozen ruff format --check client/backend admin/backend shared/python client/tests admin/tests shared/tests scripts conftest.py
uv run --frozen pytest client/tests admin/tests shared/tests -q
pnpm -r lint
pnpm -r test
pnpm -r build
pnpm test:rules
uv run --frozen python scripts/build_functions.py --discovery-venv
uv run --frozen python scripts/quality/check_source_package.py
```

pytest 透過根目錄 conftest 禁用 dotenv 並使用 ci 假 key 與替身。Rules 驗證需 Java 21／Firebase CLI 15.33.0，對四庫測試匿名及 Firebase 已登入讀寫拒絕。Functions builder 匯出各自鎖定 dependencies，獨立載入入口並檢查路由分離；檔案清單再確認內建 Skills 存在、機密與原始資料排除。

## 5. 瀏覽器與可靠性工具

瀏覽器合成腳本位於 `client/tests/browser_*.mjs` 與 `admin/tests/browser_*.mjs`，用 Playwright 驗證桌面／手機。依腳本說明設定 `PLAYWRIGHT_MODULE`、`BROWSER_BASE_URL` 與專案外輸出目錄。合成攔截測試不呼叫付費模型；實際 preview 的 Cookie、SSE、Cloud Tasks、Storage、向量查詢需另外驗收。

可靠性工具位於 `admin/tests/reliability`。CLI 用隱藏提示或密碼檔登入，再提交及輪詢 jobs；先用 dry-run／prepare-only 核對，明確指定 live 才送出。其 TypeScript bridge 以 Node 26 驗證，與前端建置 Node 24 的要求分開。

[可靠性工具](../../../admin/tests/reliability/README.md)、[四層評估](../../../admin/tests/reliability/FOUR_LAYER.md)、[效能工具](../../../admin/tests/reliability/BENCHMARK.md) 保留各自指標定義。法名命中、來源 ID 與合成案例不證明法律品質。

## 6. 部署與回復

```bash
uv run --frozen python scripts/deploy.py --environment preview --service all
uv run --frozen python scripts/configure_admin_workers.py --environment preview --apply
```

首次資源設定與 password CLI 見完整操作手冊。正式使用 production；腳本先發布 Admin／Client 後端，再發布前端。preview channel 有效 30 天，以部署 JSON 的實際 URL 為準。CI main/dev 改用 WIF／ADC 與受限 deploy SA；本機 workflow 檔存在不代表遠端已生效。

Cloud Tasks 與 Scheduler 使用各環境指定的 OIDC identity／audience；worker 位於同一 Admin Function。job lease、checkpoint、receipt 對帳及物件 generation 用於安全恢復。未知外部模型結果不自動重複呼叫。

回復前停止匯入／刪除。程式回復選擇已知可用的新架構版本，不能重新開放舊固定 token。設定用最新 revision 寫回核對值；資料按備份與 receipts 修復。error ID 與計數用於排查，不能以關閉身份驗證或反覆重試掩蓋失敗。

## 7. 文件建置

Markdown／diagram JSON 為來源；SVG、Mermaid、HTML、PDF 為衍生物。在獨立文件環境安裝 ReportLab、pypdf 及中文字型，執行：

```bash
DOC_PYTHON=/path/to/docs-python bash docs/technical-report/scripts/build.sh
```

[文件工具](../scripts/README.md) 提供連結與中文抽取檢查；詳細報告輸出至專案外，生成後逐頁檢查中文、表格與頁尾。
