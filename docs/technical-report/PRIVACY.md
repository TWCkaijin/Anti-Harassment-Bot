# 瀏覽器自動隱私處理

更新日期：2026-10-09。官方前端在本機遮罩完成後自動送出，首次與後續訊息均不顯示人工確認視窗。正式環境是否部署此版本須另行確認。操作流程見 [使用者手冊](manuals/使用者手冊.md)。

## 資料路徑

原文輸入 → 瀏覽器本機規則遮罩 → 固定請求快照 → 後端 → 後端第二層遮罩 → 模型／檢索。

`privateRequest.ts` 處理一般聊天、依摘要重新回答、管理診斷及行為測試；它共用 `clientPrivacy.ts` 的欄位白名單、遮罩與不可變快照登記。訊息、兩種角色的歷史、摘要、舊版 facts 與追問資料均納入處理。準備失敗或遭取消時不呼叫聊天 API；切換對話、修改摘要及連線版本變更的請求擁有者檢查仍保留。

目前正式辨識器仍是本機規則。常見電話、email、台灣身分證件格式、卡號或長編號、IP、網址及明示姓名／地址欄位會遮罩；一般日期、法條、角色與 110／113／119 會保留。瀏覽器小模型尚未通過辨識品質驗收，僅存在獨立驗證頁；本次取消視窗不代表小模型或持久化遮罩對照表已整合。

## 自動送出與相容性

- 已移除人工確認視窗、確認佇列及前端管理開關。後端／舊執行紀錄中的 `enable_client_privacy_review` 暫留相容欄位，官方前端不再依它切換行為；即使為 `true` 或缺漏，也不恢復確認視窗。
- `sendChat` 與管理測試傳送層仍只接受本機處理後登記的不可變請求物件；原始 request、複製或篡改物件不能直接送出。後端 PII 設定仍獨立。
- 自動重試與管理端 PII 比較重用同一份快照，不重新讀取表單。診斷中的「輸入處理前」指後端收到的本機處理後文字。
- 追問 token 是簽章而非加密；解碼後包含未選取的選項也要檢查。未知格式、多餘欄位或敏感文字會使整份追問 metadata 被移除，改以遮罩後的一般訊息送出；不改寫簽章。
- Excel 批次仍保留整批預覽及明確開始／續跑操作；不會逐筆彈出 PII 確認視窗。
- 快照登記是官方前端的流程約束，不是對任意 HTTP 客戶端的遮罩證明。

## 圖片與儲存範圍

圖片維持既有 PNG、JPEG、GIF、WebP 原圖上傳，每張最多 5 MiB；前後端驗證 MIME、base64、檔頭與大小。`enable_image_upload=false` 仍停用圖片入口，API 回傳 `422 image_upload_disabled`。圖片不做 OCR、EXIF 或臉部去識別；原圖也可能留在本機紀錄與匯出。

自動規則可能漏掉姓名、住址、單位、罕見事件或跨段資訊。新訊息與該次送出摘要保存本機處理後文字；既有紀錄、備份及手動儲存摘要不會批次清除，選入下一次請求時會重新遮罩。取消視窗不代表自由文字或圖片已完全匿名。

本次不變更雲端設定、部署、資料匯入或供應商保存政策。人工維護的 prompt、法源、直接 API 客戶端及平台 IP／連線資訊不在這項前端處理範圍內。
