# Admin 前端

獨立管理介面包含系統設定、Prompt、Skills、診斷測試、批次預測、本機遮罩驗證及檢索資料庫。使用 Node.js 24、pnpm 10.27.0；從專案根目錄執行：

```bash
pnpm install --frozen-lockfile
pnpm --filter @rag/admin dev
pnpm --filter @rag/admin test
pnpm --filter @rag/admin lint
pnpm --filter @rag/admin build
```

本機前端為 `http://127.0.0.1:5174`，`/api` 由 Vite 代理至 `http://127.0.0.1:8001`。管理 API 固定使用同源 `/api/v1/admin`；HttpOnly cookie 保存 session，修改請求加上記憶體中的 CSRF token，管理密碼及 token 不寫入 localStorage。

設定、Skills、Rerank 模型與資料庫列表使用分頁內的記憶體／sessionStorage 快取，效期 10 分鐘、最多 40 筆／約 2 MiB。重新載入仍先線上驗證登入，再依環境與 session 分隔快取；登出或登入失效即清除。手動重新整理、修改前的版本核對，以及來源／片段詳細內容均直接讀取伺服器。修改與觀察到工作完成後會清除相關列表快取；未顯示資料庫分頁時停止其工作輪詢。

「本次診斷測試」沿用一般對話的多輪輸入、圖片附件、選項、摘要編輯／重新回答與心情顯示。桌面為左側選單、中間對話、右側暫時設定；手機透過設定按鈕展開側欄。送出時固定當次設定，僅影響測試，不會寫回環境。診斷頁籤保留最近兩次結果並支援只切換後端 PII 的比較；切換管理功能時，診斷對話、批次預測與本機遮罩驗證會繼續執行並保留結果；重新載入或登出會中止瀏覽器工作並清除對話及暫時設定。本機遮罩驗證也會在登入到期時停止。背景執行限同一個開啟中的頁面，不提供關閉瀏覽器後繼續執行的能力。

測試、來源檔案解析、確認後的資料匯入及刪除均建立背景工作，前端輪詢工作狀態。JSON／JSONL／CSV／XLSX 先在背景掃描欄位，管理者明確對應內容與來源資訊欄位後，再排隊產生完整預覽。檔案解析與欄位對應不執行 embedding；確認預覽後才建立匯入工作。

伺服器的匯入草稿與工作紀錄支援重新載入、重新登入後恢復；切換管理分頁也保留目前欄位選擇。工作紀錄提供分頁、進度、取消與明確重試；未知外部計費結果的工作需先勾選重複費用確認。既有資料若無可驗證完整來源，僅列出完整片段，不推測來源分組。

「批次預測」統一一般對話及適用法規模式，支援任意 Excel 欄位、多欄組合、固定文字與 1–10 輪腳本。ID、分類、參考答案及覆核條件均可不指定。每輪引用的空白欄會阻擋整批準備；一般對話最多 100 案、法規模式最多 5,000 案。預覽、固定設定及確認送出後才呼叫模型。

並行案例可選 1／2／4／8（預設 1），每個案例測次各自保存歷史與摘要，輪次依序執行。所有案例共用 2.1 秒派送間隔；暫停等待已送出輪次完成，停止則取消進行中工作。失敗輪次需人工重試；401／403／409／429 或連線結果不明會停止新派送。下載 JSON 可保留完整逐輪證據及人工覆核；支援匯入舊 `behavior-tests-v1` 紀錄，匯入後必須重新確認才可續跑。宣告式 `batch-template-v1` 範本不包含登入或送出授權。

結果 Excel 是原活頁簿的副本，在最右側輸入欄後集中插入各測次、各輪的結果區，原有右側欄位向右移。來源列號、其他工作表及儲存格樣式保留；執行前若發現公式、名稱範圍、合併、表格、繪圖或其他不支援結構，要求另存純值測資。無原活頁簿的內建案例或 JSON 紀錄，另匯出逐輪紀錄報告。法規正確率以每案測次的最後一輪計算。

「本機遮罩驗證」在所有環境使用目前的 Admin 登入狀態。元件延遲載入，模型須手動載入；切換管理功能仍繼續計算；登入到期時停止並保留報告，登出釋放模型。載入後以 3 則獨立合成控制案例執行基本辨識檢查，顯示實際片段與遮罩結果；至少命中一個預期片段且沒有執行錯誤才啟用完整驗證，基本檢查不計入品質分數。正式與 Preview build 都包含舊網址 `/masking-validation.html` 的導向入口，會進入 `/#masking`，不再建立獨立登入頁。

本機執行器提供 8 個 worker。`scripts/configure_admin_workers.py` 已準備 Cloud Tasks 的 8 並行上限，仍維持每秒 2 次派送；必須另外套用雲端設定才會改變已部署環境容量。

合成瀏覽器檢查位於 `admin/tests/browser_*_smoke.mjs`。啟動 Vite 後，設定 `PLAYWRIGHT_MODULE` 指向已有 Playwright 安裝並以 Node.js 執行；所有 API 由合成回應取代，並封鎖非本機請求。這些檢查不代表已部署、真實模型品質或法律正確性。

目前已完成 Admin Preview 的桌面／手機真實登入與瀏覽驗證，包含七個分頁、`preview`／`app_dev` 環境識別、HttpOnly Cookie 與登出後 401；未由此驗證資料寫入、模型品質或正式切換。完整證據邊界與待辦見 [遷移報告](../../docs/MIGRATION_REPORT.md)，部署與日常維運見 [維運說明](../../docs/OPERATIONS.md)。
